# LibMessageStudio

> The standard Nintendo C library for message files across 3DS, Wii U, and Switch games.

---

**Note:** This repo is a decompilation of the **3DS version** of MessageStudio only.
For the Switch version, see [Trippixyz/LibMessageStudio](https://github.com/Trippixyz/LibMessageStudio).

---

## MessageStudio File Formats

| Extension | Full Name | Description |
|-----------|-----------|--------------|
| `MSBT` | MessageStandardBinary (`MsgStdBin`) | MessageStudio standard message file |
| `MSBF` | MessageFlowBinary     (`MsgFlwBin`) | MessageStudio flow file |
| `MSBP` | MessageProjectBinary  (`MsgPrjBin`) | MessageStudio project file |
